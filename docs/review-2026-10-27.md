## 报告 1:internal/api(7/10)

### 发现

**[P1] catalog 对 `http://` 仓库三个接口全部失效(catalog.go:181)**:`registryURL` 硬编码 `https://%s%s`,而 registry.go:66-72 `normalizeHost` 明确保留 `http://` 前缀,probe.go 与 skopeo 链路均支持 HTTP。明文 HTTP 仓库"测试连接"通过但 Repos/Projects 必然失败;`buildListRef`(catalog.go:120-138)拼出 `docker://http://host/path` 同样失败。建议复用 probe.go 的 scheme 剥离逻辑。

**[P1] multipart 临时文件泄漏(chartupload.go:57)**:`c.MultipartForm()` 后从未 `form.RemoveAll()`;超过 64MB(MaxMultipartMemory,router.go:23)的部件写系统临时文件,每个大 chart 上传泄漏一份直至重启。建议 defer `form.RemoveAll()`。

**[P1] upload-paths 无文件大小上限(chartupload.go:179)**:`chart.ParseFile(p)` 无 size 检查即 `os.ReadFile` 整读;`runOne` 的 `os.ReadFile(u.FilePath)`(chartupload.go:330)同样整读 1GB。建议先 `os.Stat` 校验。

**[P2] XFF 伪造绕过 IP 限速 + loginGuard 内存无界(login_limiter.go:23)**:gin 默认信任所有代理,`c.ClientIP()` 可伪造;records 仅成功登录时清理。
**[P2] 改密码不吊销已签发 token(auth.go:159)**:JWT 无版本/iat 校验。
**[P2] 上传请求体无总量上限(router.go)**:无 MaxBytesReader。
**[P2] 推送失败的临时文件永久残留(chartupload.go:305-312)**:`os.Remove(tmpDir)` 非空目录静默失败,重启即孤儿。建议启动清扫 `irs-chart-*`。
**[P2] SSRF 面:catalog/test 以服务端身份探测任意 host(registry.go:194)**:含 169.254.169.254/localhost,insecure 跳 TLS,`io.ReadAll` 无上限。内网单 admin 属设计取舍,建议至少禁环回/链路本地。
**[P3] task.go Create 180 行超长函数 + DTO 校验重复**;**[P3] 错误处理不一致**(settings.go:75 Save 错误未查、auth.go:87、task.go:286 Count 未查);**[P3]** harborRepos 静默吞单 project 错误(catalog.go:241);registry 密码一旦设置无法清除(空=保留)。

### 测试盲区
catalog(HTTP 仓库)用例完全缺失;login_limiter 锁定到期/成功 reset 另一 key/XFF;chartupload 文件名穿越(`../x.tgz`)、UploadPaths 非 tgz、目录展开 >100、超大文件;task Create:uniqueRefs 去重后为空、非法 Mode、2000 边界、自动匹配源=目标拒单;Stream:客户端断开、心跳分支、broadcast 丢事件;settings Save 失败分支;auth 改密后旧 token。
